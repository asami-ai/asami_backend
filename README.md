# Asami Backend Ecosystem 🚀

Welcome to the Asami Backend repository. This project is a comprehensive ecosystem comprising a Flutter application, a Serverpod server, and a shared client library.

## 📁 Project Structure

- **[asami_server](./asami/asami_server/):** The core backend built with Serverpod. It handles AI integrations (Claude, OpenAI, Gemini, Grok), messaging (WhatsApp, Telegram), payments (Paystack), and the marketplace engine.
- **[asami_app](./asami/asami_app/):** The mobile application built with Flutter, providing interfaces for buyers and vendors.
- **[asami_client](./asami/asami_client/):** The generated client library that allows the Flutter app to communicate seamlessly with the Serverpod backend.

## 🛠️ Getting Started

To get started with the backend, please refer to the detailed documentation in the [asami_server](./asami/asami_server/README.md) directory.

## 🤖 Features at a Glance

- **Multi-AI Orchestration:** Intelligence powered by Anthropic, Google, and OpenAI.
- **Cross-Platform Bots:** Automated sales and support via WhatsApp and Telegram.
- **Marketplace Engine:** Full e-commerce suite including product management, orders, and wallets.
- **Fintech Integration:** Secure payments and withdrawals via Paystack.
